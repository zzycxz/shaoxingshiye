# 产品定位

## 产品主张

绍兴师爷不是替用户站队的"职场裁判"，也不是教人钻营的厚黑手册，而是一个同时处理情绪、信息和行动的职场决策参谋。它帮助用户从混乱叙述、聊天记录、邮件或会议纪要中建立职场格局档案，识别事实与读心之间的距离，比较汇报、坚持、协商、留证、观察或退出的真实代价，并把建议转化为可发送的话和可执行的下一步。立身原则是"佐治而不弄权"——替用户看清局面、办好差事，但守住法律与人格的边界。

## 核心用户与价值表达

| 用户 | 典型困境 | 价值表达 |
| --- | --- | --- |
| 要向上汇报的用户 | 讲了很多没被记住，请示没有回音 | 一页纸汇报骨架、选择题请示、颗粒度按领导风格校准 |
| 想提意见的用户 | 怕得罪领导，说了没用还背锅 | 信任额度评估、三步进言法、台阶设计与留痕时机 |
| 被塞活的用户 | 同事甩活、跨部门塞任务、领导无限加需求 | 分层拒绝：拒内容不拒人、把优先级决策交回去 |
| 被批评背锅的用户 | 情绪上头，当众下不来台 | 先判型再回话（道歉 vs 澄清）、24 小时书面闭环、防背锅清单 |
| 请假与婚育中的用户 | 不好意思开口，怕影响评价 | 权利沟通模板：给排期方案，权利不辩论；2025 典型案例落地 |
| 谈钱与去留的用户 | 加薪不会谈，被裁不会算 | 谈判一页纸、N/N+1/2N、当场三不、竞业限制新规 |
| 处理人情的用户 | 随份子、求人、饭局分寸拿不准 | 人情账簿原则、饭局底线、渠道元规则（什么话走什么渠道） |
| 实习与外包用户 | 转正模糊、权益差异 | 转正标准书面化、结构性差异认知、自保标准不降级 |

## 差异化能力

1. **情绪与决策一体化**：先接住情绪，再分清事实，最后给能执行的选择；不确定用户要建议还是只想被听见时先问。
2. **五类职场档案**：用户/领导/同事/事件/假设分开存，来源门禁由脚本强制（记录只进事件、推断只进假设），支持离职调岗的失效标注。
3. **证据分级**：较强证据、理论框架、流行说法、经验策略四档分开用，法律条目对官方原文并标注时效。
4. **意图红线**：审手段也审主要效果——"如实但经挑选以促成他人处分"同样拒绝；代过、告密、行贿、伪造证据一律不设计。
5. **安全层经红队验证**（脱敏用例见 `examples/redteam_cases.md`）：自伤风险优先于一切（12356 转介清单），危机对话不追问档案。
6. **沉默与表达同级**：何时不说、何时不回复有专文与实证底座（组织沉默研究），沉默的实证刻度直接可用。
7. **对话演练**：师爷扮演领导/HR/面试官陪练，可开对抗模式，五维复盘不打虚构分数。
8. **话术骨架速查**：53 条骨架集中成库，"这句怎么回"第一屏给可复制成品。
9. **行业语境适配**：工程建设与通信网络的角色链、惯例与红线区速查。
10. **动态插拔**：默认不安装，`skill_plug.sh` 按需挂载 ZCode/Codex/Claude Code，拒绝双挂。

## 非目标

- 不诊断心理疾病，不替代心理治疗或医疗服务。
- 不充当律师、劳动仲裁员或紧急救援机构；不代替法律意见。
- 不预测领导意图为事实；动机推断必须标注为推测。
- 不帮助构陷、代过隐瞒、行贿、伪造证据或以违法手段取证。
- 不因性别、年龄、地域、学历、残障、性取向改变建议质量；不把刻板印象当依据。
- 不在未同意时保存跨任务档案；长期记忆保持精简有界，不把记忆同步到仓库或外部服务。
- 不直接读取、解密或导出企业微信、飞书、钉钉等平台数据。

## 产品成功信号

当前仓库没有遥测。未来评估应使用匿名或合成案例，关注：

- 首次接触是否用紧凑问卷收集最小必要信息；紧急时是否先处理眼前问题。
- 回答是否准确区分事实、推测和未知；是否只追问 1–3 个真正影响决策的问题。
- 用户只要回复话术时，第一屏是否有一条符合原文与用户口吻的可发送成品。
- 是否给出明确首选、理由、三分支后续和停止条件。
- 高压场景（裁员、仲裁、霸凌）是否正确切换到自保与安全优先流程。
- 不同行业、用工形式、性别与年龄下建议质量是否一致。
- 长期记忆是否经过首次同意、只写高价值变化、每次提示且可撤销，达到上限时不膨胀。

## 路线图

- 建立匿名合成案例评测集，覆盖汇报、拒绝、背锅、裁员与危机场景。
- 为法律条目加入更新时间与复核状态元数据（司法解释、典型案例）。
- 为长期记忆增加可视化审阅与字段级编辑界面；当前版本使用本地命令。
- 扩展行业语境包（当前仅工程建设与通信网络），按用户需求增补。
- 增加英文内容层，同时保留中国职场文化语境。
- **承诺台账**：在档案 event 域记录"谁答应了什么、何时到期"，到期提醒与复盘（21 号批量复盘的自然延伸）。
- **外部协作场景**：甲方、客户、监理的沟通与商务分寸（联动 15 号行业语境，目前仅 03 号一小节）。
- **IM 细分场景**：群接龙与信息收集、节日红包与群发祝福、下班后与周末消息的分寸、审批与日程邀约的接受/拒绝、截图外传第三方的边界。
