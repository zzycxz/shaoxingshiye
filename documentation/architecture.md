# 架构说明

## 产品概览

绍兴师爷是一个本地 Agent Skill，由行为指令、界面元数据、按需加载的 Markdown 知识库和可选的本地脚本组成。仓库不包含服务器、前端应用、账号系统或遥测；用户同意后，记忆脚本在操作系统用户数据目录创建有界 SQLite 文件，绝不写入仓库。

## 组件

| 组件 | 路径 | 职责 |
| --- | --- | --- |
| 行为内核 | `SKILL.md` | 定义触发场景、首次建档、五步分析流程、输出格式和安全边界 |
| 界面元数据 | `agents/openai.yaml` | 定义显示名称、简介和默认提示词 |
| 核心知识 | `references/knowledge/` | 提供证据分级、领导关系科学、影响与谈判、劳动法、职场文化、幕学原典与书单索引 |
| 实用策略 | `references/practical/` | 提供汇报、提意见、催办、拒绝、背锅应对、请假婚育、离职谈判、人情往来与话术材料 |
| 验证器 | `scripts/validate_skill.py` | 检查结构、元数据、必需文件、上下文预算、回归标记、运行时边界、断链和占位符 |
| 本地记忆 | `scripts/memory_store.py` | 执行同意门禁、来源校验、五类档案、限量、撤销、失效标注和硬删除 |
| 动态插拔 | `scripts/skill_plug.sh` | 按需挂载/卸载到 ZCode、Codex、Claude Code 的 skill 目录，默认不安装 |
| 项目文档 | `documentation/` | 记录产品意图、运行流程、权限与自动化边界 |

## 运行方式

宿主（ZCode / Codex / Claude Code 等）根据 Skill 描述决定是否加载 `SKILL.md`。被调用后，代理先检查是否存在已同意的本地精简档案，只读取当前问题需要的压缩上下文，再按情境读取一到三份参考文档。最终输出是情绪承接、事实拆分、明确建议、可发送话术、观察窗口和停止条件；消息发送仅在用户明确授权下进行；不读取聊天软件数据库。

`SKILL.md` 只保留核心流程、路由和安全边界，默认按问题读取 1–3 份参考。项目文档和原始研究不属于运行时安装白名单；运行时只同步 `SKILL.md`、`agents/`、`references/`、`scripts/` 以及存在时的 `assets/`。

仓库运行 `python3 scripts/validate_skill.py` 校验项目与运行内容；白名单安装副本运行 `python3 scripts/validate_skill.py --runtime`，不要求项目治理文件存在。

## 信任边界

1. **用户 → 代理**：用户可能提供高度敏感的薪酬、绩效、劳动争议、职场关系与心理健康信息。
2. **Skill 指令 → 模型推理**：`SKILL.md` 是行为引导，不是不可绕过的程序级强制器。
3. **参考文档 → 模型上下文**：知识文件（尤其法律条目）可能过时，不能视为实时法律或危机数据库；引用前复核时效。
4. **模型建议 → 现实行动**：用户决定是否发送消息、签字或采取行动；经用户明确授权的动作除外，Skill 不自动执行其他副作用。
5. **代理 → 本地记忆**：只有首次明确同意后才能写入；脚本执行来源门禁（记录只进事件、推断只进假设）、条数限制和撤销机制。
6. **代理 → 外部平台**：无任何直接集成；企业微信/飞书/钉钉内容仅由用户主动粘贴或导入。

## 已知风险与假设

- 宿主没有本地文件权限或脚本不可用时，档案只能在当前任务中使用；代理必须诚实说明没有持久化。
- SQLite 可提供事务与条数上限，但不能替代磁盘加密、操作系统账号隔离或宿主安全控制。
- 模型可能将推测写得过于肯定，必须依赖"事实／推测／未知"流程降低风险；人格化判断只能进假设层。
- 法律与劳动政策具有时效性和地区性（如司法解释（二）2025-09-01 施行），引用前需要复核日期与地区。
- 性别、年龄、学历、地域刻板印象可能污染建议，行为内核明确要求按用户具体处境给方案。
- 提示词安全边界不是程序级安全控制；高风险使用仍依赖宿主模型政策。

## 不适用的系统文档

- 无邮件发送，因此无 `emails.md`。
- 无定时或后台任务，因此无 `cron.md`。
- 无公开 Web 路由或 SEO 表面，因此无 `seo.md`。
