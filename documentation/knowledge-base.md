# 知识库治理

## 分层

| 层级 | 目录 | 用途 |
| --- | --- | --- |
| 行为规则 | `SKILL.md` | 决定何时询问、怎样分析、怎样输出和何时切换安全流程 |
| 核心知识 | `references/knowledge/` | 证据分级、领导关系科学、影响与谈判、劳动法、职场文化、幕学原典与索引 |
| 实用材料 | `references/practical/` | 汇报、提意见、催办、拒绝、背锅应对、请假婚育、演练与话术脚手架 |

幕学原典（《佐治药言》《幕学举要》等）作为本门方法论进入知识层，与机关秘书学构成"古典—当代"两极；只转译可观察、可纠正、可退出的能力，权谋类内容（《鬼谷子》《荣枯鉴》等）仅作机制与风险识别的对照素材。托名伪书（如通行本《挺经》）不引。

## 证据等级

1. **较强证据**：元分析、系统综述、大型纵向研究、正式统计和现行法律文件。
2. **理论框架**：可用于提出问题，但不能直接诊断个体或预测领导意图。
3. **流行说法**：可帮助理解用户语言，必须明确证据局限。
4. **经验策略**：机关经验与话术多属此类，以适用条件、预期效果、暴露风险和长期代价呈现。

## 包容性要求

- 不预设体制内外、行业、用工形式（正式/实习/外包/派遣/自由职业）与办公形态。
- 不把性别、年龄、地域、学历、残障、性取向写成命运（"35 岁没机会""女性该温和"类表述先说明证据状态）。
- 自由职业者把"领导"读作"客户"、"晋升"读作"涨价与续约"即可对齐，不单设低质量分支。
- 对所有处境使用同一核心标准：合法、留痕、可退出、互惠、修复能力。

## 更新规则

- 法律、政策、求助渠道信息引用前复核日期与地区（司法解释（二）为 2025-09-01 施行版）。
- 新增研究时优先补充原始或权威来源，不只添加二手总结。
- 修改实用话术时保留"适用场景—效果—代价—下一步"结构，并同步骨架速查总库（18 号）。
- 新增知识文档时只在运行确实依赖时加入必需文件清单；不设置最低篇数，不以数量激励膨胀。
- 删除内容时检查 `SKILL.md` 路由和所有相对链接。
- 不把真实用户的私密案例直接沉淀进公开知识库。
- 默认按当前问题读取 1–3 份参考；需要证据或风险校准时再增量加载，不批量载入全库。
