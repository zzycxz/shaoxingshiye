# 08 古典进谏智慧与伦理转译

## 定位

把《韩非子·说难》《贞观政要》《智囊》和机关经验（参谋助手论、机关三部曲）里的向上沟通智慧，转译成现代、合法、可退出的能力。处理方式：**只保留机制洞察，剥离人身依附与权谋操作**。

## 韩非《说难》：进言的风险结构（理论框架）

核心命题："凡说之难，在知所说之心，可以吾说当之。"进言的困难不在口才，在于理解听者的心理与利害。

可转译的洞察：

| 说难原理 | 现代转译 |
| --- | --- |
| "所说在为高，而阴为利"——对方表面求名实为求利 | 听出领导的**真实议程**：他说重视质量，KPI 是什么？ |
| "夫事以密成，语以泄败" | 敏感议题控制知情范围；书面的正式性要与内容的敏感度匹配 |
| "大意无所拂忤，然后为说" | 先在方向上达成一致，再谈细节分歧；开场即对立则后面全废 |
| "旷日弥久，而周泽既渥"——信任需要时间积累 | 进言的额度与信任存量成正比；新关系先存款（兑现小事）再支取（提异议） |

剥离的部分：韩非为游士设计的"顺意承欲、伪装亲近"技术不转译——那是把关系当猎物。

## 贞观政要：信任-进谏循环（案例材料）

魏征与唐太宗提供了"说难"理论的实践对照组：

- "未信而谏，则以为谤己"——不被信任时的直言被当作攻击（与 Edmondson 心理安全感研究、威权领导与建言负相关的实证一致）。
- "信而不谏，则谓之尸禄"——被信任后不直言是失职。信任的建立是为了**用**，不是收藏。
- 太宗容谏的结构性条件：制度化的纳谏渠道 + 领导层的自我利益（明君人设）——现代对应：正式反馈渠道 + 让领导看到"听真话的收益"。

## 参谋助手论与机关经验（经验策略）

可转译的能力（保留）：

1. **预判信息需求**：领导被问什么之前先备好数据——服务的是职责不是人身。
2. **结构化表达**：结论、选项、代价、建议，一页纸讲清。
3. **进退时机**：议程窗口、情绪窗口、场合公私的判断。
4. **留痕自保**：重要请示与确认落在书面（现代版有劳动法依据，见知识 05）。

剥离的糟粕（拒绝转译）：

- **代过**：替领导隐瞒或揽责——现代语境里可能把用户拖入违法
- **人身依附**：把自己定义为主人家的附属——与追随者研究（主动共创 > 被动服从）相反
- **揣摩迎合到说违心话**：逢迎的实证证据本就混合，长期摧毁信任与自我尊重

## 智囊与案例的使用方式

冯梦龙《智囊》等案例库的用法：当**情境演练素材**而非行动模板——"如果你是故事里的官员，此时怎么选？"分析其信息结构、利害与风险，然后翻译成现代职场等价物。故事里"成功"的构陷手段（离间、构陷、诈术）直接标记为不可用。

## 红线（与 SKILL.md 一致）

不提供：告密与构陷同事、行贿与利益输送、伪造证据、欺上瞒下的具体操作、以隐私或把柄要挟。用户带着这类诉求来时，说明风险、给合法替代（正式渠道、证据、退出谈判）。

## 检验转译是否合格

三个问题：这个能力**可观察**吗（有具体行为）？**可纠正**吗（反馈来得了）？**可退出**吗（不把自己锁死在某个关系/谎言里）？三问有一个不过，就不转译。
