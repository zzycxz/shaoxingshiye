# 04 难相处同事与毒性领导应对

## 先分类（Gallo 八型简化 + 毒性判定）

对付之前先判定性质——**难相处 ≠ 毒性**。对照知识 06 的模式清单（频率+持续时间+权力差）；达到霸凌模式 → 直接走 04 后半部分的阶梯应对，话术安抚解决不了系统性问题。

常见类型速查（Gallo 框架，流行说法级）：

| 类型 | 行为 | 相处要点 |
| --- | --- | --- |
| 不安全感领导 | 揽功、防你越级、怕被比下去 | 主动给可见度、请他背书，减少威胁感 |
| 被动攻击同事 | 答应了不做、阴阳怪气 | 任务落到书面+期限；不接情绪钩子 |
| 控制狂 | 微管理、改你一切产出 | 提前给进度减少其焦虑；一次明确"我需要多大自主权" |
| 抢功者 | 汇报时你的工作变他的 | 书面留痕+先发制人的进展通报（见 06） |
| 甩锅侠 | 出错时责任流向你 | 边界声明+证据链（见 06） |
| 消息黑洞 | 关键信息绕过你 | 建立第二信息源；重要事项书面确认"如有遗漏请补充" |

## 通用四原则

1. **行为记录化**：难相处的相处，从"感觉"改为"日期+事件+原话"。既是心理校准（不放大）也是证据（不丢失）。
2. **不接情绪钩子**：被动攻击与阴阳怪气的燃料是你的反应。回应只对事实层："你指的具体是哪件事？"（一次平静的澄清好过十次沉默）。
3. **边界一次说清**：对重复越界行为，一次明确声明+此后机械执行："这个部分归我负责，改动前我们先对一下。"——坚定但不对抗升级。
4. **关系多元化**：不在一个人的评价里押全部身家；LMX、协作网络多点布线，单点毒性不致命。

## 毒性领导：应对阶梯（知识 06 的实操版）

1. **记录 4 周**：每天 3 行（事件/原话/在场者），周末复盘一次模式。
2. **健康检查**：睡眠、情绪、躯体化信号——出现任何自伤念头立即转介（12356，见知识 06）；异常持续 1 周建议专业支持、2 周强烈建议（EAP/心理咨询/12356），这优先于任何职场动作。
3. **最小暴露优化**：能书面不口头、能公开不私下、会议留纪要；把"被他单独针对"的场景结构性减少。
4. **一次正式沟通**（可选，评估安全后）："我想聊聊协作方式。我注意到 X（行为），它对我产出的影响是 Y。我希望以后 Z。"——对事、具体、带出口。反应冷淡不奇怪，这一步的价值是**正式化+你的态度留档**。
5. **HR/上级渠道**：带记录正式提出；同时启动 07 的退出评估——渠道走不走得通不影响你准备好退路。
6. **止损线**：健康持续受损或被要求违法 → 离开是正确选项，按 07 拿好补偿再走。

## 被孤立/边缘化

- 先核对事实：是系统性隔离（会议、信息、资源三缺）还是关系自然疏远？前者可能是刻意的（记录），后者重建连接即可。
- 重建路径：从最有共同利益的一两个人开始（跨部门协作里最容易找到盟友，见 03）；工作可见度（文档、群里高质量的公开输出）比社交讨好更有效。
- 长期孤立 + 打压模式 → 知识 06 判定，04 阶梯照走。

## 红线

- 不建议以牙还牙（构陷、散布隐私、拉帮结派对轰）。
- 不建议未评估就公开对线或社交媒体曝光（名誉反诉风险，先咨询律师）。
- 涉及性骚扰、暴力威胁 → 知识 05 法律路径，不走本文件话术。
- 体制内/国企校准：被批评与背锅场景的公开对线成本更高，优先正式申诉渠道（人事、纪检、组织部门），书面材料的格式与措辞参照知识 07 公文节。
