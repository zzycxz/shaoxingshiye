# 00 导读与使用分级

## 本库结构

- **practical/01–08**：场景化实操指南——汇报、提意见、跨部门、难相处、被批评、证据留存、离职谈判、档案。每份自带话术骨架、后续分支与停止条件。
- **practical/09–16**：扩展场景——求职面试与入职、加薪晋升谈判、会议发言与团队协作、待人接物与人情往来、展示价值、带团队、行业语境速查、沉默的艺术。
- **practical/17–21**：速查、演练与个人事务——对话演练（陪练、预演与复盘）、话术骨架速查总库、拒绝与摊派、请假婚育与个人事务、办公 IM 适配（企业微信/飞书/钉钉）。
- **knowledge/01–09**：证据分层的知识文档——分级规则、领导关系科学、影响与说服、反馈与情绪、劳动法、霸凌、中国职场文化、古典转译、书单索引。

## 使用分级（对应知识 01 的四档）

| 用户处境 | 读什么 | 深度 |
| --- | --- | --- |
| "这句怎么回 / 这封邮件怎么写" | practical/18 骨架速查 → 对应场景文件，直接出成品 | 话术层，不展开理论 |
| "领导什么意思 / 我该怎么办" | 先 practical 对应场景，再按需 1 份 knowledge | 诊断层 |
| "这样合法吗 / 我能要求什么" | knowledge/05 + practical/06、07 | 法律要点层，个案提示咨询律师 |
| "为什么 / 有什么依据" | knowledge 对应文件 + 09 索引 | 证据层，如实分级 |

## 场景路由

场景 → 指南的完整路由表由 SKILL.md 的"按需加载"一节统一维护，本文件不重复罗列，避免两处改不同步。

## 适配说明

本库不预设用户的行业、体制、用工形式（正式/实习/外包/派遣/自由职业）与办公形态（现场/远程/混合）：指南给的是结构与原则，案例里的行业细节按用户自述替换。自由职业者把"领导"读作"客户"、把"晋升"读作"涨价与续约"即可对齐。

## 通用话术规则（所有指南共享）

1. **一条消息一个主动作**：不把汇报+解释+抱怨+请求堆在一段里。
2. **先成品后解释**：第一屏给可复制发送的内容，再给时机与代价。
3. **三分支收尾**：任何发送都预告积极/含糊/拒绝三种回复的下一步。
4. **口吻校准**：长度对齐对方、保留用户惯用语、媒介匹配（重情绪面谈、重留痕书面）。
5. **停止条件**：每个策略都写明何时放弃、转哪个指南。
