# 20 请假、婚育与个人事务

## 定位

个人事务的沟通不是求恩赐：**请假是法定权利，沟通目标是顺利拿到 + 不留把柄**。覆盖请假、婚育相关、家庭照护。原则：提前说、给排期方案、降低对方的管理成本；权利问题不辩论，只谈安排。

## 请假沟通

**事假**（提前 1–3 天）："X 日请事假一天（家里有事）。手头 A 已提交，B 我回来后 X 日前补上；期间急事可找 [同事]，我已和他打过招呼。"——给排期方案，领导批的是"安排"而不只是"假"。

**病假**（当天早上说）："身体不适，今天请假一天，明天视恢复情况复工。紧急事项电话可找我。"——不必给诊断细节（隐私），说清影响与复工预期即可。

**急假**（家人急病/事故）："家里有急事我得立刻走，今天的 [会议] 请 [同事] 代一下，晚上我再看消息。"——先走后补流程，事后补一条书面记录（06）。

**年假被卡**："年假是法定的（《职工带薪年休假条例》），我计划 X 月休，工作已安排好。这个时间不行可以换时间，但今年需要休完。"——权利不辩论，只协商时间。

**被拒怎么办**：问清理由（排期/人手），给 2 个替代时间；两个都被拒且无理由 → 书面申请留痕（06），向 HR 或工会（12351）咨询。

## 婚育相关

**面试被问婚育计划**："我的婚育计划不影响这份工作的投入，这个岗位我最关心的是 [岗位内容]。"——就业性别歧视相关规定下可拒绝回答；答也只答"不影响"，不答具体计划。记录下这家公司问过（这是文化信号，供你选 offer 时参考）。

**孕期告知**：书面（邮件/微信）告知 + 预产期 + 交接计划。告知是孕期保护（医疗期内不得依《劳动合同法》第 40/41 条解除、产假待遇）的前提——**留痕价值优先于沟通礼仪**。

**孕期被变相调岗降薪**：违法。2025 人社部/最高法《第四批劳动人事争议典型案例》明确"孕期变相调岗降薪违法"（知识 09 第三节）。应对：书面异议（06）、不签变更合同、按 07 走仲裁（知识 05）。

**哺乳期**：每天 1 小时哺乳时间（《女职工劳动保护特别规定》），被占用可主张。

## 家庭照护与其他

- **照护家人**（老人/孩子就医）：同请假骨架——事由一句话 + 排期方案 + 交接人。
- **副业被问**：法律不禁止业余兼职，但劳动合同可能有约定；"下班时间的个人安排，不影响本职"——不主动展开。
- **办公室恋情**：法律不禁止；公司制度要求披露的按制度执行（不披露的风险自评），不设计隐瞒话术。

## 停止条件与红线

- 因婚育被歧视（拒录、辞退、边缘化）→ 04/06/07 + 劳动监察（12333）——这是违法问题，不是沟通问题，停话术走程序。
- 请假被报复性考核打压 → 06 记录 + 07 评估去留。
- 持续失眠、情绪低落需要请病假就医：直接去，健康优先（知识 06 转介清单）。
