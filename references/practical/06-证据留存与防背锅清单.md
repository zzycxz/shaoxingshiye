# 06 证据留存与防背锅清单

## 原则（知识 05 的实操化）

- **原始载体**：微信/邮件证据的效力在原始记录（手机原件、邮箱原邮件），不在截图转存。重要对话不删、不换设备前先备份。
- **孤证难认定**：证据链 = 消息 + 邮件 + 文档版本 + 考勤 + 流水 + 证人互相印证。单一截图常常只是"各执一词"。
- **合法性**：只留自己可见范围内的记录；不 hacking、不偷录私密空间、不引导对方说出可剪辑的话——违法取证的"证据"会反噬。
- **平时留痕，不是事后补**：背锅发生后再找证据，多数已经没了。

## 日常留痕清单（防背锅五件套）

1. **口头决定落地**：任何口头交办/变更，当天跟一条文字："按刚才沟通，我将做 X，期限 Y，有出入请指正。"——不确认也不影响其留痕价值（对方沉默+你已尽核实义务）。
2. **会议必纪要**：谁在场、谁说了什么（关键原话）、决定了什么、谁负责、期限；24 小时内群发。异议期一过即成为"共同事实"。
3. **交接与边界书面化**："这部分由 A 负责，我提供 B 支持"——写入邮件或协作文档，抄送双方领导（升级透明）。
4. **版本与时间戳**：重要文档用带版本号的文件名+修改记录；关键节点用邮件附件存档（邮件的时间戳比本地文件硬）。
5. **定期归档**：每月一次，把当月的承诺、决定、争议打包存到个人设备/私人邮箱——**在职时就要做，离职时设备会被收回**。

## 高危场景对号入座

| 场景 | 必留什么 |
| --- | --- |
| 领导口头指示疑似违规 | 你请求书面确认的记录（"麻烦邮件确认下'按 A 处理'"+ 对方坚持口头/不回）——这本身就是证据 |
| 跨部门甩锅 | 会议纪要 + 邮件往来 + 你方的及时通报（03 的三级火箭全程留痕） |
| 被架空/信息隔离 | 你主动请求信息的记录（"请拉我进 X 群/抄送 Y"无回应） |
| 绩效突然反转 | 此前的表扬、评分、加薪记录（证明"前后不一致"） |
| 加班与工作量 | 考勤、深夜邮件时间戳、排班表——主张加班费与"客观情况变化"都要 |
| 拖欠/降薪/调岗 | 工资流水、劳动合同、调岗通知——拒收调岗要书面表达异议并继续上班（避免被认定旷工） |

## 微信记录的标准保存法

1. 不删除对话、不清理存储（记录在原始账号里）。
2. 关键段落另外截图（防对方撤回）+ 记下时间点。
3. 大案要案前做**公证**（知识 05：公证固定显著增强效力）。
4. 注意工作号 vs 私人号：公司配的设备/账号里的记录离职时带不走，重要事项尽早转发到个人渠道（仅限自己有权接触的信息）。

## 监控边界（个保法角度的自知）

- 公司对工作设备、工作时间的监控在"告知+必要"范围内通常合法——**工作号里别说不想被看到的话**。
- 公司监控延伸到私人聊天、私人邮箱、非工作时间 → 越界，可主张权利（知识 05）。
- 对称地，用户自己取证也守同样边界。

## 红线

- 不伪造、不篡改、不全选择性剪辑制造误导性证据链。
- 不把取证变成钓鱼（诱导他人说出本不会说的话用于威胁）。
- 证据的用途是自保与主张权利，不是要挟筹码（"我有你把柄"= 敲诈勒索风险）。
